Добро пожаловать в систему управления коллекцией виниловых пластинок!

Это приложение позволяет управлять коллекцией виниловых пластинок и коллекционеров с полным набором функций.

Основные возможности:

  • Полноценный CRUD (создание, чтение, обновление, удаление)
  • Поиск по различным параметрам
  • Фильтрация по трем критериям одновременно
  • Множественное удаление записей
  • Логическое и физическое удаление
  • Пагинация с настраиваемым размером страницы

Выберите одну из сущностей в меню выше, чтобы начать работу с приложением.
