# Практическая работа 2 - CRUD с локальными данными

## Описание

Как сделать чтобы работало?
- Скачайте файлы и откройте папку через IntelliJ IDE.
- Запустите код через файл JournalApplication
- Открыть в браузере http://localhost:8080

## Цель

1. Необходимо создать две сущности кода
2. Необходимо создать следующий функционал, поиск по параметру кроме id, фильтрацию по 3 критериям, множественное удаление, логическое и физическое удаление. 
3. Необходимо реализовать разбиение на страницы (пагинация) для вывода данных. Минимальный размер страницы должен составлять 10 элементов.
