# Практическая работа 3 - Работа с БД

## Описание

Как сделать чтобы работало?
- Скачайте файлы и откройте папку через IntelliJ IDE.
- Открыть файл database_script и открыть его в pgadmin4
- Создать базу данных в pgadmin через скрипт
- Поменять username и password в файле application.properties
- Запустите код через файл DemoApplication
- Открыть в браузере http://localhost:8080

## Цель

1. Необходимо просто подключить выбранной СУБД, сделать валидацию на каждое поле с помощью аннотаций(пример @NotBlank или @Size).
2. Сделать 5 сущностей, которые в будут связаны 1к1, 1кМ, МкМ реализовать методы CRUD для каждой таблицы, если у таблицы есть связь они должны выводиться в выпадающий список.
3. Сделать тоже самое что на оценку 4 и 3 реализовать поиск пагинацию, фильтрация, сортировку, логическое удаление физическое удаление.
